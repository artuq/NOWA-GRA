# Font Attribution

**VT323-Regular.ttf** — by The VT323 Project Authors (Peter Hull), licensed under
the **SIL Open Font License 1.1** (https://openfontlicense.org).

A monospace pixel/terminal font, used project-wide as the default UI font
(`project.godot` → `gui/theme/custom_font`), imported with antialiasing
disabled + subpixel positioning off for crisp pixel-perfect rendering matching
the pixel-art icons.

OFL permits free use, embedding, and bundling in commercial software. The font
file may be redistributed with the game. Recommended (not strictly required for
embedded use): credit "VT323 (SIL OFL 1.1)" in the in-game credits screen once
it exists — tracked alongside the icon attribution in docs/tech-debt-register.md.
