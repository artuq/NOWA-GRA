# Bug Register

Convention (Sprint 10, task 10-6): one file per bug, `BUG-NNN-short-slug.md`, incrementing NNN.
Severity: S1 Critical (data loss/crash/blocker) | S2 Major | S3 Minor | S4 Cosmetic.
Statuses: Open / In Progress / Fixed / Won't Fix. Same-session fixes still get filed
retroactively — the register is the historical record `/bug-triage` and `/gate-check` read.
